# 応用情報 学習管理

合格教本（令和08年 応用情報技術者 合格教本）の1周と、その後の過去問演習を管理するiPhone向けWebアプリです。ホーム画面に追加して使い、データはiPhoneの中だけに保存されます。

## 公開のしかた（GitHub Pages、無料）

1. GitHubで新しいリポジトリを作る。名前は `ap-study`、公開範囲は **Public**（無料プランのGitHub PagesはPublicのみ。公開されるのはアプリのコードだけで、記録したデータは公開されません）。
2. リポジトリの画面で「Add file」→「Upload files」を選び、このフォルダの中身をすべてドラッグして「Commit changes」。
   - `index.html` / `manifest.webmanifest` / `sw.js` / `icons` フォルダ（中の画像4つ）/ `README.md`
3. 「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を「main」「/(root)」にして「Save」。
4. 1〜2分待つと `https://（GitHubのユーザー名）.github.io/ap-study/` で開けるようになります。

## iPhoneに入れる

1. iPhoneの **Safari** で上のURLを開く。
2. 共有ボタン →「ホーム画面に追加」→「追加」。
3. 以後は **必ずホーム画面のアイコンから** 開く（Safariで開いたページとはデータが別になります）。
4. 初回設定で、教本の目次を見て各章の開始ページと本文の最終ページ（11.6の最後のページ）を入れる。

一度開けば、オフラインでも動きます。

## データの守り方

- データはiPhoneの中だけにあります。ホーム画面からアプリを消すとデータも消えます。
- 「設定」→「書き出す」でJSONファイルを「ファイル」アプリなどに保存できます。7日書き出していないと、今日の画面でお知らせが出ます。
- 機種変更や入れ直しのときは「読み込む」で戻せます。
- 書き出したファイルをClaudeとの会話に添付すれば、進捗を見て計画の相談ができます。

## アプリを更新するとき

ファイルを差し替えたら、`sw.js` の `VERSION` を上げてからアップロードします。次に通信できる状態でアプリを開いたときに新しい版に入れ替わります（データはそのまま残ります）。

## 主な仕様

- メイン：1〜9章を章の順番どおり。サブ：10〜11章を毎日少しずつ並行。
- 計画は「ページ数×章の重さ」で割り振り（速め0.8：1・2・5章、標準1.0、丁寧1.3：4・8章。設定で変更可）。節の残りが3ページ以下なら同じ日に読み切る。日曜は調整日。
- 記録した勉強時間から章ごとの1ページあたりの分数を出し、重さを補正（同じ目安の未読の章にも反映）。補正した重さは次に組み直すときに使う。
- 直近7日の実際のペースから読み終わる日を予測（3日分の記録がたまってから）。
- 遅れが2日分を超えたとき、予測が目標日より3日以上遅いとき、2日分以上先行しているときに「組み直す」を案内。遅れなら目標日を1/4までの範囲で延ばす案、先行なら目標日を早める案か1日の量を軽くする案を出す。計画が変わるのはボタンを押したときだけ。
- 章を読み終えると、翌日に見直し、7日後に午前過去問10問が自動で入る（6問未満ならさらに7日後）。△の節は3日後に読み直し。
- 日付の切り替えは午前4時（深夜の勉強は前日分）。
